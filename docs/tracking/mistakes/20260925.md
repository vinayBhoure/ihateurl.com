### Orphaned dev server after stopping its background task
- Error: dev — a second `npm run dev` exited 1 with "Another next dev server is already running" (PID 13952). That old server also served stale Tailwind CSS: classes added after it started (`md:order-last`, `md:gap-12`, `space-y-12`) were missing, so the landing rows did not alternate.
- Cause: I stopped the background `npm run dev` task with TaskStop. That ended the npm wrapper but left the `next dev` node process running on port 3000.
- Fix: `Stop-Process -Id 13952`, then one fresh `npm run dev`; CSS correct after reload (dev only, no commit).
- Avoid: stop a dev server by its PID (`Get-NetTCPConnection -LocalPort 3000` → `Stop-Process`), not only its wrapper task; if new Tailwind classes don't apply, restart dev before debugging the code.
